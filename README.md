# readingFish

Настольная программа для Windows и Linux, которая превращает текстовые файлы в
речь голосом, заданным вами, через сервер [fish-speech](https://github.com/fishaudio/fish-speech).

Замысел простой: держать все тексты и голоса в одном месте, размечать длинный
текст на части, отправлять их на сервер и получать готовый звук. Без Python,
без ручной настройки окружения и без пересборки при смене голоса.

## Возможности

### Проекты

Каждый проект — это один текст со своим голосом и своими параметрами синтеза.
Проекты создаются из текстового файла, их можно переименовать, удалить и открыть
папку с результатом из интерфейса.

Всё хранится рядом, обычными файлами: `~/fishApp/projects/<id>/project.json`
с настройками проекта, `source.txt` с исходным текстом, `audio/part_NNNN.wav` с
отдельными частями и `audio/result.wav` со склеянным результатом. Ничего не
прячется в базе — можно смотреть, править и переносить руками.

### Страница проекта

- **Правка исходного текста** встроенным редактором: кегль и жирность шрифта,
  перечитывание файла с диска, разбиение на части с оценкой их количества.
- **Синтез** с прогрессом по частям, с остановкой на середине и продолжением
  с места остановки. Уже готовые части при повторе не перегенерируются.
- **Перегенерация всего** — когда нужно сменить интонацию целиком.
- **Прослушивание** отдельных частей и собранного результата, с кнопкой
  остановки и индикатором состояния.
- **Пересборка** `result.wav` из готовых частей, без обращения к серверу.
- **Правка одной части** с немедленной переозвучкой этой части и пересборкой
  результата.
- **Вставка пауз** прямо в текст: пункт контекстного меню ставит тег `(pause)`
  в позицию курсора, с отступами от соседних символов. Сработает и `Ctrl+Z`.
- Тег паузы переносить вручную не обязательно, но многоточие в тексте при
  разбиении на части никогда не считается точкой разреза, и ни одна часть не
  заканчивается многоточием.

### Параметры синтеза

Свои у каждого проекта, редактируются в диалоге и хранятся в `project.json`:
длина текста за один проход модели, потолок токенов, nucleus sampling, штраф за
повторы, temperature, фиксированное зерно генератора, кеширование референса на
сервере, нормализация чисел и режим задержки.

Границы значений совпадают с реальной схемой сервера, поэтому недопустимое
значение отсекается ещё до отправки, а не приводит к ошибке от сервера. Сброс
к умолчаниям — одна кнопка.

### Голоса

Список голосов сервера, добавление нового из аудиофайла, удаление, проверка
того, загружен ли образец на сервер. Образец можно прослушать прямо в списке.
Голос, выбранный в проекте, отправляется на сервер автоматически, если его там
ещё нет.

### Настройки приложения

Адрес сервера и проверка связи с ним, голос по умолчанию для новых проектов,
целевой размер части, потолок токенов, temperature, оформление редактора
исходного текста и доля высоты, которую он занимает. Всё в `~/fishApp/settings.json`.

Температура и потолок токенов в настройках приложения — значения по умолчанию
для новых проектов. У конкретного проекта они перекрываются его собственными
параметрами синтеза.

## Сборка

Нужен **.NET 9 SDK**. Собранные файлы самодостаточны: ни .NET, ни другие
зависимости на целевой машине не требуются, приложение запускается сразу.

Под Windows всё собирается одним скриптом, он же собирает `.deb` для Linux
прямо на Windows:

```powershell
.\build.ps1
```

Частично:

```powershell
.\build.ps1 -Target windows   # только readingFish.exe
.\build.ps1 -Target linux     # только автономный бинарник для Linux
.\build.ps1 -Target deb       # только .deb
```

На Linux или в WSL то же самое делает `build.sh`:

```bash
./build.sh          # всё вместе
./build.sh deb      # только .deb
```

### Что получается

| Файл | Назначение |
|---|---|
| `dist/win-x64/readingFish.exe` | Windows x64, один файл, запускается без .NET |
| `dist/linux-x64/readingFish` | Linux x64, один файл |
| `dist/readingfish_<версия>_amd64.deb` | Пакет для Debian и Ubuntu с ярлыком в меню |

Обе платформы собираются из одного исходника: [Avalonia](https://avaloniaui.net)
на .NET 9, воспроизведение звука — через winmm в Windows и ALSA в Linux,
если устройство недоступно, файл открывается системным плеером.

Пакет `.deb` ставит программу в `/usr/lib/readingFish/`, ярлык в меню — в
`/usr/share/applications/`, иконку `image.png` — в
`/usr/share/icons/hicolor/512x512/apps/`. После установки
`update-desktop-database` и `gtk-update-icon-cache` вызываются автоматически.

## Требования к серверу

Нужен запущенный fish-speech с доступным HTTP-API. Адрес и проверка связи — на
странице настроек, по умолчанию `http://127.0.0.1:8080`. Программа сама создаёт
голоса на сервере из выбранных образцов при первом использовании.
